TIMER · iPhone & iPad

Ton temps. Ton rythme.

Timer accompagne tout ce qui se déroule par étapes. Planifie les étapes, fixe les durées et enregistre tes routines pour le quotidien, la concentration, l’apprentissage, le travail et plus encore.

Démarrage rapide

Les cinq premières séances démarrées par installation sont gratuites. Les démarrages suivants nécessitent un achat Premium unique via Apple, sans nouveau renouvellement automatique. Les achats permanents vérifiés et anciens abonnements annuels restent reconnus selon leurs droits ; gère ou résilie les abonnements chez Apple. Apple affiche le prix avant l’achat et gère paiement et restauration. Timer ne collecte pas de données de carte et n’exploite pas de serveur de paiement.

Timer Premium

Démarrage rapide

  1. Ouvre Timer sur iPhone ou iPad. Au premier lancement, choisis le mode simple ou complet et confirme les consignes d’utilisation.
  2. Ouvre le minuteur depuis l’aperçu. Un intervalle de cinq minutes est proposé. Appuie sur Démarrer.
  3. Ouvre les packs d’activités depuis l’aperçu. Choisis une séquence universelle, concentration, apprentissage, lecture, travail, routines quotidiennes, cuisine ou mouvement.

Commander le minuteur

Démarrer lance le compte à rebours. Pause l’interrompt, Reprendre le poursuit, Suivant passe à l’intervalle suivant. Réinitialiser revient au début ; Fin termine la séance.

  1. Démarrer lance le compte à rebours. Pause l’interrompt, Reprendre le poursuit, Suivant passe à l’intervalle suivant. Réinitialiser revient au début ; Fin termine la séance.
  2. L’écran indique le temps restant de l’intervalle et du programme entier. En paysage, le compte à rebours est affiché en grand.
  3. Configure le son, les vibrations, les annonces vocales et le signal de mi-temps. Les réglages iOS influencent aussi les signaux.
  4. Les intervalles facultatifs démarrent après confirmation. Le bilan apparaît directement après le dernier intervalle ou le refus des intervalles facultatifs. Les séances terminées peuvent apparaître dans l’historique.

03

Intervalles et séries

Ouvre les packs d’activités depuis l’aperçu. Choisis une séquence universelle, concentration, apprentissage, lecture, travail, routines quotidiennes, cuisine ou mouvement.

  1. Ouvre les packs d’activités depuis l’aperçu. Choisis une séquence universelle, concentration, apprentissage, lecture, travail, routines quotidiennes, cuisine ou mouvement.
  2. Modifie les étapes prédéfinies, leur ordre et leurs durées. Enregistre une nouvelle série numérotée ; les séries existantes et la séquence active restent inchangées. Charge-la et lance le minuteur.
  3. Pour le mouvement, choisis toi-même les entrées du catalogue ; Timer ne crée pas de programme automatiquement. Les deux profils restent séparés. Les durées sont des exemples, pas des recommandations ni des consignes de sécurité.
  4. Ouvre Modifier les intervalles à l’aide des curseurs. Ajoute un intervalle, choisis une désignation prédéfinie et définis sa durée.
  5. Réorganise, supprime ou ajoute des intervalles facultatifs. Configure les tours et les pauses selon tes besoins.
  6. Enregistre le programme actuel comme nouvelle série avec un nom numéroté disponible dans la liste. Charge, modifie, renomme, ajoute aux favoris ou supprime les séries dans le mode actif.
  7. Utilise l’export JSON ou importe une nouvelle série CSV/JSON. Les anciens fichiers PhysioClock appartiennent au mode mouvement.

Plan hebdomadaire et rappels

Choisis une ou plusieurs séries par jour dans le plan hebdomadaire, dans l’ordre souhaité.

  1. Choisis une ou plusieurs séries par jour dans le plan hebdomadaire, dans l’ordre souhaité.

Historique et aperçu

L’aperçu mensuel et l’historique indiquent les séances terminées et leur durée enregistrée dans le mode actif.

  1. L’aperçu mensuel et l’historique indiquent les séances terminées et leur durée enregistrée dans le mode actif.
  2. Le mode complet propose des synthèses supplémentaires. Le changement de mode préserve les plans et historiques séparés.
  3. Si la modification des durées est activée, corrige une séance par incréments disponibles. Tu peux supprimer des entrées. Aucun nouveau ressenti ne peut être enregistré.

06

Sauvegarde et import

Ouvre Aide et informations → Sauvegarde et suppression. Exporte un fichier JSON du mode actif et protège-le.

  1. Ouvre Aide et informations → Sauvegarde et suppression. Exporte un fichier JSON du mode actif et protège-le.
  2. Pour importer une nouvelle série, choisis un fichier CSV/JSON compatible, confirme le nom attribué automatiquement. Les séries existantes restent intactes. Les imports remplacent les noms libres. Les anciennes notes et entrées du catalogue ne sont pas restaurées.
  3. Export et partage nécessitent ton action explicite. Les fichiers peuvent contenir des données personnelles ; protège-les. Le lieu de stockage choisi peut être externe à l’appareil. L’import d’une série ajoute une série ; la restauration complète confirmée remplace les données du mode actif. La suppression locale concerne ce mode. Désactiver iCloud ne supprime pas les copies cloud ; gère séparément sauvegardes et fichiers exportés.
  4. Aucune nouvelle donnée de ressenti n’est collectée. Les anciennes données et le cache de synchronisation, s’ils sont lisibles, sont transférés dans un stockage local protégé par iOS et exclu des sauvegardes d’appareil. Dans Sauvegarde et suppression, tu peux les supprimer explicitement. Les autres programmes et historiques restent intacts.
  5. Les anciennes versions pouvaient enregistrer des contenus personnels dans iCloud. Cette version ne lit ni ne modifie ces anciens enregistrements. Dans Rappels et iCloud, tu peux supprimer les deux anciens enregistrements après confirmation explicite. Sauvegarde d’abord les données nécessaires et mets à jour tous les appareils ; les anciennes versions peuvent recréer ces enregistrements. Les données locales et le nouvel enregistrement neutre restent intacts.

Mode mouvement facultatif

Timer démarre en mode neutre. Active les exercices de mouvement dans Aide et informations → Réglages et iCloud → Réglages → Mode d’utilisation pour afficher les programmes de mouvement, le catalogue et les objectifs. Les programmes, plans et historiques sont séparés. Change de mode uniquement lorsque le minuteur est arrêté et la synchronisation terminée. Timer organise les activités, intervalles et routines choisis par toi. Le mode mouvement facultatif sert uniquement à l’orientation générale et à la mesure du temps. Il n’évalue pas les symptômes, ne pose aucun diagnostic et ne recommande aucun traitement individuel.
