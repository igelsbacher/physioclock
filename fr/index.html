TIMER · iPhone & iPad

Ton temps. Ton rythme.

Un minuteur pour le quotidien, la concentration et les routines personnelles. Crée tes intervalles, enregistre tes programmes et garde une vue sur ton temps.

Démarrage rapide

Les cinq premières séances démarrées sont gratuites. Ensuite, un abonnement annuel Timer Premium actif est nécessaire. Il se renouvelle automatiquement sauf résiliation au moins 24 heures avant échéance. Apple affiche le prix avant l’achat.

Timer Premium

Démarrage rapide

  1. Ouvre Timer sur iPhone ou iPad. Au premier lancement, choisis le mode simple ou complet et confirme les consignes d’utilisation.
  2. Ouvre le minuteur depuis l’aperçu. Un intervalle de cinq minutes est proposé. Appuie sur Démarrer.
  3. Utilise les réglages pour modifier les intervalles, leur nom et leur durée. Enregistre le programme comme série si nécessaire.

Commander le minuteur

Démarrer lance le compte à rebours. Pause l’interrompt, Reprendre le poursuit, Suivant passe à l’intervalle suivant. Réinitialiser revient au début ; Fin termine la séance.

  1. Démarrer lance le compte à rebours. Pause l’interrompt, Reprendre le poursuit, Suivant passe à l’intervalle suivant. Réinitialiser revient au début ; Fin termine la séance.
  2. L’écran indique le temps restant de l’intervalle et du programme entier. En paysage, le compte à rebours est affiché en grand.
  3. Configure le son, les vibrations, les annonces vocales et le signal de mi-temps. Les réglages iOS influencent aussi les signaux.
  4. Les intervalles facultatifs démarrent après confirmation. Les séances terminées apparaissent dans l’historique ; la récupération méditative relève du mode mouvement facultatif.
Guide
03

Intervalles et séries

Ouvre Modifier les intervalles à l’aide des curseurs. Ajoute un intervalle, donne-lui un nom et définis sa durée.

  1. Ouvre Modifier les intervalles à l’aide des curseurs. Ajoute un intervalle, donne-lui un nom et définis sa durée.
  2. Réorganise, supprime ou ajoute des intervalles facultatifs. Configure les tours et les pauses selon tes besoins.
  3. Enregistre le programme actuel comme nouvelle série. Charge, modifie, renomme, ajoute aux favoris ou supprime les séries dans le mode actif.
  4. Utilise l’export JSON ou importe une nouvelle série CSV/JSON. Les anciens fichiers PhysioClock appartiennent au mode mouvement.
Guide
04

Plan hebdomadaire et rappels

Choisis une ou plusieurs séries par jour dans le plan hebdomadaire, dans l’ordre souhaité.

  1. Choisis une ou plusieurs séries par jour dans le plan hebdomadaire, dans l’ordre souhaité.
  2. Sous Rappels et iCloud, règle les heures et les jours. Autorise les notifications iOS pour recevoir les rappels.
  3. Un rappel ne démarre pas automatiquement le minuteur. Ouvre l’application et lance ton programme.
Guide
05

Historique et aperçu

L’aperçu mensuel et l’historique indiquent les séances terminées et leur durée enregistrée dans le mode actif.

  1. L’aperçu mensuel et l’historique indiquent les séances terminées et leur durée enregistrée dans le mode actif.
  2. Le mode complet propose des synthèses supplémentaires. Le changement de mode préserve les plans et historiques séparés.
  3. Si la modification des durées est activée, corrige une séance par incréments disponibles. Tu peux supprimer des entrées. Aucun nouveau ressenti ne peut être enregistré.
Guide
06

Sauvegarde et import

Ouvre Aide et informations → Sauvegarde et suppression. Exporte un fichier JSON du mode actif et protège-le.

  1. Ouvre Aide et informations → Sauvegarde et suppression. Exporte un fichier JSON du mode actif et protège-le.
  2. Pour importer une nouvelle série, choisis un fichier CSV/JSON compatible, donne un nom et confirme. Les séries existantes restent intactes.
  3. La restauration complète remplace les données du mode actif après confirmation. Vérifie le mode : les anciens fichiers PhysioClock appartiennent au mode mouvement.
  4. La suppression locale concerne le mode actif. Gère séparément les exports, sauvegardes d’appareil et copies cloud.
Guide

Mode mouvement facultatif

Timer démarre en mode neutre. Active les exercices de mouvement dans Aide et informations → Réglages et iCloud → Réglages → Mode d’utilisation pour afficher les anciens programmes, le catalogue, les photos et les objectifs. Les programmes, plans et historiques sont séparés. Change de mode uniquement lorsque le minuteur est arrêté et la synchronisation terminée.
