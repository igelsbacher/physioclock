# PhysioClock – Website und aktueller Entwicklungsstand

**PhysioClock 3.32.12 (Build 93)** ist die einzige aktuelle App-Version, auf welche die Website und die vier PDF-Handbücher Bezug nehmen.

PhysioClock ist eine SwiftUI-App zur selbstorganisierten zeitlichen Begleitung von Bewegungs- und Physiotherapieübungen auf iPhone und iPad. Die Website bietet Anleitungen, einen 100-Übungen-Katalog, Beispielvorlagen, Trainingsziele, Fortschritts- und Befindensübersichten sowie Erläuterungen zu Sicherung und freiwilliger iCloud-Synchronisation.

## App-Funktionen

Die App unterstützt selbst definierte Trainings-Sets, Timer, Übungen, Fortschrittsanzeigen, Monatsübersichten, Ziele, Befindenseinträge, Erinnerungen, Export/Import und – optional – iCloud-Datensynchronisation. Die ersten 30 gestarteten Trainingseinheiten pro Installation sind kostenlos. Danach erlaubt ein einmaliger Premium-Kauf weitere Trainingsstarts; es gibt kein Abonnement.

## Technischer Stand

Dieses GitHub-Repository enthält die **Website**, nicht das komplette SwiftUI-/Xcode-App-Projekt. Die aktuellen Quelltexte werden getrennt gepflegt. Die App ist kein Ersatz für Diagnose, Therapie oder medizinische Beratung.

Eine Veröffentlichung im App Store oder ein erfolgreich signierter iOS-Build wird durch die Bereitstellung dieser Website nicht bestätigt.
