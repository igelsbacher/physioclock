TIMER · iPhone & iPad

Your time. Your rhythm.

Timer accompanies anything that happens in sequence. Plan steps, set durations and save routines for daily life, focus, learning, work and more.

Quick start

The first five started sessions per installation are free. A one-time Premium purchase through Apple is intended for further starts, without new automatic renewal. Verified previous permanent purchases and existing annual subscriptions are honoured according to their entitlement status; manage or cancel existing subscriptions with Apple. Apple displays the price before purchase and handles payment and restoration. Timer does not collect card details or operate a payment server.

Timer Premium

Quick start

  1. Open Timer on iPhone or iPad. On first launch, select Simple or Full mode and acknowledge the usage notice.
  2. Open the timer from the overview. A five-minute interval is available by default. Tap Start to begin.
  3. Open Activity packages from the overview. Choose a universal sequence, focus, learning, reading, work, daily routines, kitchen or movement.

Timer controls

Start begins the countdown. Pause stops it temporarily, Resume continues, Next skips to the next interval. Reset returns to the beginning; End finishes the session.

  1. Start begins the countdown. Pause stops it temporarily, Resume continues, Next skips to the next interval. Reset returns to the beginning; End finishes the session.
  2. The display shows remaining time for the current interval and the entire programme. Landscape orientation emphasises the countdown.
  3. Configure sound, vibration, speech and halfway signals in Settings. iOS settings also affect signals.
  4. Optional intervals start only after confirmation. The summary appears immediately after the final interval or declining optional intervals. Completed sessions can appear in history.

Intervals and sets

Open Activity packages from the overview. Choose a universal sequence, focus, learning, reading, work, daily routines, kitchen or movement.

  1. Open Activity packages from the overview. Choose a universal sequence, focus, learning, reading, work, daily routines, kitchen or movement.
  2. Edit the predefined steps, their order and durations. Save a new numbered set; existing sets and the current sequence remain unchanged. Load the set and start the timer.
  3. For movement, choose catalogue entries yourself; Timer does not automatically create a movement programme. The two data profiles remain separate. Example durations are not recommendations or safety instructions.
  4. Open Edit intervals using the sliders. Add an interval, choose a predefined label and set its duration.
  5. Reorder, remove or add optional intervals. Set rounds and breaks as needed.
  6. Save the current programme as a new set with an available numbered name from the list. Load, edit, rename, favourite or delete existing sets in the active mode.
  7. Use JSON export or import a new set from CSV/JSON. Legacy PhysioClock files belong to movement mode.

Weekly plan and reminders

Choose one or more saved sets per weekday in the weekly plan and arrange them in your preferred order.

  1. Choose one or more saved sets per weekday in the weekly plan and arrange them in your preferred order.
  2. Under Reminders & iCloud, select reminder times and weekdays. Allow iOS notifications if you wish to be reminded.
  3. Reminders do not start a timer automatically. Open the app and start the selected programme yourself.

History and overview

The monthly overview and history show completed sessions and recorded duration in the active mode.

  1. The monthly overview and history show completed sessions and recorded duration in the active mode.
  2. Full mode includes additional summaries. Switching the movement switch preserves separate weekly plans and history.
  3. If time editing is enabled, correct a recorded session in the available increments. Individual entries can be deleted. No new wellbeing entries can be recorded.

06

Backup and import

Open Help & Information → Backup & deletion. Export a JSON backup of the current mode and store it securely.

  1. Open Help & Information → Backup & deletion. Export a JSON backup of the current mode and store it securely.
  2. Import as a new set: choose a matching CSV/JSON file, confirm the automatically assigned set name. Existing sets remain intact. Imports replace free-text names. Legacy notes and catalogue entries are not restored from backup.
  3. Backup exports and sharing occur only on your explicit action. Files may contain personal content; store them securely and remember they may reside off-device depending on the chosen destination. Importing a set adds a set; explicitly confirmed full restoration replaces data in the active mode. Local deletion affects the selected mode. Turning sync off does not remove cloud copies; device backups and saved files must be managed separately.
  4. No new wellbeing entries are collected. Existing wellbeing data and the former sync cache, if readable, are moved to local storage protected by iOS file protection and excluded from device backups. Under Backup & deletion you can explicitly delete legacy local wellbeing data and the former sync cache. Other movement programmes and history remain.
  5. Earlier app versions could store personal content in iCloud. This version no longer reads or updates those old cloud records. Under Reminders & iCloud you can delete the two legacy app records after explicit confirmation. Back up anything you need locally and update all devices first; older versions can recreate the records. Local data and the new neutral record remain.
Guide

Optional movement mode

Timer starts in neutral mode. Only when you enable movement exercises in Help & Information → Settings & iCloud → Settings → Application mode do movement programmes, catalogue and goals appear. Each mode has separate sets, weekly plans and history. Switch only with the timer stopped and no sync in progress. Timer organises self-selected activities, intervals and personal routines. Optional movement mode provides general orientation and timekeeping only. It does not assess symptoms, diagnose or recommend individual treatment or therapy.

Cookies and browser storage

The website sets no cookies of its own. Only if explicitly enabled, the browser remembers language and learning checklist ticks until the tab closes. This is local session storage; you can reset it. The site does not transmit these preferences to us.
